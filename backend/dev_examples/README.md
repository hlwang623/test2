## 🚀 使用方法

### 快速导入（推荐）

在项目根目录执行：

```bash
cd backend
python scripts/seed_dev_samples.py
```

执行后会自动：
1. 创建测试用户 `dev_test`（密码: `test123456`）
2. 创建科目「概率论与数理统计」
3. 将样本数据导入到数据库
4. 复制文件到 `uploads/` 目录

### 登录系统

导入完成后，使用以下账号登录系统：

- **用户名**: `dev_test`
- **密码**: `test123456`

### 清理测试数据

如果需要重置环境，执行：

```bash
cd backend
python scripts/seed_dev_samples.py --clear
```

**注意**: 这会删除 `dev_test` 用户及其所有关联数据！

## ➕ 添加新样本

### 步骤1: 准备样本数据

将 MinerU 解析后的文件夹放入 `dev_samples/` 目录：

```bash
dev_samples/
├── README.md
├── 概率论与数理统计/      # 已有样本
└── 你的新样本/             # 新增样本
    ├── images/
    ├── *.md
    └── ...
```

### 步骤2: 更新脚本配置

编辑 `backend/scripts/seed_dev_samples.py`，在 `TEST_SUBJECTS` 列表中添加配置：

```python
TEST_SUBJECTS = [
    {
        "name": "概率论与数理统计",
        "description": "盛骤、谢式千、潘承毅编著 第五版（开发样本）",
        "sample_folder": "概率论与数理统计"
    },
    # 添加你的新样本
    {
        "name": "你的教材名称",
        "description": "教材描述",
        "sample_folder": "你的新样本"  # dev_samples/ 下的文件夹名
    }
]
```

### 步骤3: 运行导入脚本

```bash
cd backend
python scripts/seed_dev_samples.py
```

## 📋 样本要求

添加新样本时，请确保：

1. ✅ **包含 Markdown 文件**: 文件名不以 `README` 开头的 `.md` 文件
2. ✅ **图片在子目录**: 图片通常在 `images/` 目录下
3. ✅ **MinerU 标准格式**: 符合 MinerU 解析输出的文件结构
4. ✅ **文件完整性**: 包含所有必要的元数据文件（JSON等）

## ⚠️ 注意事项

### Git 版本控制

- ✅ **推荐提交**: README.md、小样本（< 10MB）
- ❌ **不要提交**: 超大文件（> 50MB）

如果样本过大，建议：
1. 将样本上传到团队网盘
2. 在 README 中添加下载链接
3. 在 `.gitignore` 中排除该样本文件夹

### 文件大小建议

- 单个样本文件夹建议 < 50MB
- 如果超过，考虑压缩或使用外部存储

### 敏感信息

确保样本数据**不包含**：
- 版权敏感内容（如果教材有版权限制）
- 个人隐私信息
- 内部测试数据

## 🔧 故障排除

### 问题1: 找不到 Markdown 文件

**错误信息**: `未找到markdown文件`

**解决方法**:
- 检查样本文件夹是否包含 `.md` 文件
- 确保 `.md` 文件名不以 `README` 开头

### 问题2: 样本已导入过

**提示信息**: `该样本已导入过 (文件ID: x)，跳过`

**解决方法**:
- 这是正常行为（脚本支持幂等性）
- 如需重新导入，先执行 `--clear` 清理数据

### 问题3: 数据库连接失败

**错误信息**: `无法连接到数据库`

**解决方法**:
- 确保在 `backend/` 目录下运行脚本
- 检查数据库文件是否存在
- 尝试先启动一次后端服务初始化数据库
